493문항 · 29회 · 문항별 해설 379개 · 단답·서술 암기 모드 307대표문항 · 암기카드145 · 비교표14 · 되돌리기/다시실행 포함.

2026-10-25 기준으로 54문항에 개정·정정·현행 조건을 별도 보충했습니다(전체 검토 메모 92건, 출처 34개). 원문 정답은 그대로입니다. 추가 확인 14문항은 보류 표시를 유지합니다. 모든 문항의 현행 적합을 보증하는 것은 아닙니다. 인쇄 암기노트는 22쪽으로 원문 암기 + 현행 보충편, 8쪽 연습지는 기출 원문 기준입니다.

`cbt_data.json`은 **개인 기록이 없는 빈 공개 예제**입니다. 본인의 기존 저장 파일은 웹 화면의 '불러오기'로 직접 읽으세요. 학습 기록은 현재 브라우저에 저장되며 GitHub에 자동 업로드되지 않습니다. 다른 기기로 옮길 때는 '저장하기'로 내보내야 합니다.

시험 시간과 수동 부분점수는 연습 기능입니다. 암기법은 비공식 정리본을 따르며 현재 법령을 보증하지 않습니다. 114문항의 개별 해설은 아직 미완료이고, 단답·서술 2025년 확장은 포함되지 않았습니다.
