- 인용본 시행일은 모든 문구의 최초 개정일이 아닙니다. 미래 시행 기준을 선반영하지 않으며 기존 건축물의 허가·신고·착공과 부칙·경과조치는 별도 확인해야 합니다.

## 법령 표 사진 연결

NFTC 203의 「표 2.4.1 부착 높이에 따른 감지기의 종류」를 공식 원문 이미지로 내장했습니다. 우선 단답·서술의 **15~20m 감지기 / 20m 이상 감지기 / 감지기 설치기준 복합문항** 3묶음에 연결합니다.

정답을 공개한 뒤 현행 보충의 **📋 근거 표 보기**를 펼치세요. 사진 또는 확대 버튼을 누르면 50~300% 확대·축소할 수 있습니다. 읽어야 할 행·비고, 인용본 시행일, 공식 원문·이미지 링크를 함께 표시합니다. 이미지는 HTML 안에 있어 오프라인에서도 보입니다. **현행 참고표는 출제 당시 판본과 구별**하며 원문 정답은 바꾸지 않았습니다. 이번 사진 연결은 CBT 화면에 적용했으며 인쇄 PDF에 사진을 추가하지는 않았습니다.

## PC·휴대폰 자동 동기화 — 2026-10-30

1. 위 온라인 주소를 PC와 휴대폰에서 열고 상단 탭의 **☁️ 로그인**을 누릅니다(휴대폰은 탭을 가로로 넘겨 확인).
2. 등록한 같은 아이디와 **숫자 6자리 PIN**으로 로그인합니다. 개인 기기에서는 ‘로그인 유지’를 선택할 수 있습니다(최대30일).
3. 첫 연결에서 기존 기기 기록과 서버 기록이 다르면 자동으로 덮어쓰지 않습니다. 기존 기록이 있는 기기에서 **이 기기 기록으로 클라우드 갱신**을 선택하고, 새 기기에서는 클라우드 기록을 불러오세요.
4. 이후 오답·풀이 완료·시험 결과·내 메모·단답/암기카드 학습기록을 변경하면 잠시 뒤 자동 저장됩니다. 접속·화면 복귀 및 온라인 복구 시에도 확인합니다. 진행 중 시험의 미제출 입력 답안·타이머·화면 위치는 동기화 대상이 아닙니다.

인터넷이 끊기면 기기 기록과 전송 대기를 유지합니다. 여러 기기가 각각 수정했으면 **충돌 확인**에서 어느 기록을 사용할지 직접 고릅니다. 자동 합산/최신 날짜 우선 덮어쓰기는 하지 않습니다. 교체 전 기록은 해당 기기 내부 백업에 보관합니다. 다른 기기 기록을 적용하면 이전 되돌리기 이력은 초기화됩니다.

로그인 시 기존 **💾 저장하기**는 동기화 메뉴를 엽니다. JSON 파일이 필요하면 메뉴의 **JSON 파일 백업**을 이용하세요. 비로그인 학습과 기존 파일 불러오기는 그대로입니다. 로컬 HTML 파일에서는 오프라인 학습을 사용하고, 클라우드 연결은 온라인 GitHub 주소에서 이용합니다. 처음 다른 origin의 기록을 옮길 때만 JSON으로 가져오기가 필요합니다.

기록은 본인 Cloudflare Worker/D1에 저장되며 공개 GitHub에는 올라가지 않습니다. PIN은 서버 salt+비밀 pepper+PBKDF2 해시로 저장하고 원문은 저장하지 않습니다. 공개 회원가입/비밀번호 복구 기능은 없습니다. PIN 공유 시 다른 사람이 기록을 읽거나 바꿀 수 있습니다. 공용 기기에서는 로그인 유지하지 마세요. 브라우저 접속 토큰은 학습 JSON에 포함하지 않습니다.

## 시작하기

온라인 주소를 열면 CBT로 이동합니다. 설치나 로그인이 필요하지 않습니다.

오프라인으로는 저장소에서 **Code → Download ZIP**을 눌러 압축을 푼 다음 `cbt_v2/cbt.html`을 여세요. `crops` 폴더는 HTML 옆에 그대로 두어야 이미지가 나옵니다. 프로그램 실행에는 Python·Node 설치가 필요 없습니다.

### 기존 학습 기록 가져오기 / 백업

**공개 저장소에는 개인 오답·풀이 이력·메모가 들어 있지 않습니다.** `cbt_v2/cbt_data.json`은 모든 기록이 비어 있는 예제입니다.

1. 기존 오프라인 CBT에서 **💾 저장하기**로 본인의 `cbt_data.json`을 내보냅니다.
2. 새 온라인 CBT에서 **📂 불러오기**를 눌러 해당 파일을 선택합니다.
3. 온라인에서 같은 계정으로 로그인하면 다음부터는 자동 동기화를 사용합니다. 비로그인/오프라인 파일 간에는 기존 저장/불러오기도 가능합니다.

학습 기록은 우선 현재 브라우저 localStorage에 저장됩니다. **로그인한 경우에만 본인 Cloudflare 서버와 동기화**하며 GitHub 저장소에는 기록을 업로드하지 않습니다. 오프라인 파일과 온라인 주소의 로컬 기록은 별개입니다. 브라우저 데이터 삭제·시크릿 모드 종료 등에 대비해 JSON 백업도 권장합니다. 자신의 저장 파일을 이 공개 저장소에 커밋하지 마세요.

### 되돌리기

화면 왼쪽 아래 **↶ ↷ 🕘**를 사용합니다. PC에서는 Ctrl/Cmd+Z, Ctrl+Y 또는 Ctrl/Cmd+Shift+Z를 사용할 수 있습니다. 입력 칸에서는 브라우저 기본 글자 되돌리기가 동작합니다.

- 작업 기록은 최대 120단계이며 새로고침하면 사라집니다. 저장된 학습 기록은 유지됩니다.
- 내 답안 메모·내 암기노트 글·범위 선택 옵션은 전역 되돌리기 대상이 아닙니다(파일 불러오기는 별도).
- 시험의 시간은 되돌리지 않습니다. 이미 시간이 지난 시험의 종료를 되돌리면 시간제한 없이 이어갑니다.
- 브라우저/휴대폰 뒤로가기를 되돌리기로 쓸 수 있습니다. 🕘 패널에서 해제할 수 있습니다.

## 내용과 한계

이 자료는 개인 학습용 비공식 보조자료이며 시험 주관기관의 공식 프로그램이 아닙니다.

- 이미지 기반 CBT는 문제·정답 이미지를 우선합니다. OCR 텍스트는 불완전할 수 있습니다.
- 아직 **114문항에 개별 해설이 없습니다**. 개념노트가 모든 문항의 풀이를 대신하지는 않습니다.
- 단답·서술 및 암기법은 첨부된 영상 요약 정리본(2010~2024)을 따릅니다. 숫자·용어의 출처 일치 검사는 최신 법령의 적합성을 보증하는 법률 검토가 아닙니다.
- 기출 당시 기준과 현재 기준을 구별해야 합니다. 실제 건축물에 적용하려면 경과규정·허가일 등 개별 사실관계를 확인하세요.
- 150분 등 시간 설정과 수동 부분점수는 **연습 기능**입니다. 공식 시험 시간·부분점수 규칙을 확정하는 뜻이 아닙니다.
- 단답·서술의 2025년 확장과 이미지 CBT 교차 연결은 아직 포함되지 않았습니다.
- 공개했다고 해서 제3자 원문·이미지에 대한 저작권이 이전되거나 재배포 허락이 부여되는 것은 아닙니다. 각 자료의 권리는 해당 권리자에게 있습니다. 별도의 포괄적 오픈소스 라이선스를 부여하지 않았습니다.

## 유지보수 / 검증

일반 사용자는 아래 명령을 실행할 필요가 없습니다. 개발용으로 Python 3와 Node 24 이상을 사용합니다.

```bash
# 최초 1회: 개발용 DOM 테스트 의존성(프로그램 실행 의존성 아님)
npm install --prefix _jsdom jsdom@27.0.1 --no-audit --no-fund
# 공개 저장 예제만으로 테스트 기준본 준비(이 폴더는 gitignore 대상)
mkdir -p extracted
cp cbt_v2/cbt_data.json extracted/orig_cbt_data.json
# 정리본에서 파생 데이터 다시 생성
python3 sa_parse.py
python3 sa_cluster.py
python3 sa_final.py
python3 sa_memo_check.py
python3 sa_law.py
# 수정 후 실행본 재빌드
python3 build_sa.py
python3 build_undo.py
python3 build_cloud.py  # optional cloud module must be appended after SA/undo builds
# 검증
python3 verify_cbt.py --sa
node smoke_test_cbt.js --sa
node e2e_jsdom.js
node e2e_undo.js
python3 verify_sa_law.py
node e2e_sa_law.js
node e2e_sa_tables.js
python3 build_sa_pdf.py --outdir downloads
python3 verify_sa_pdf.py downloads
python3 verify_public_release.py
```

위 smoke test의 과거 버전 저장 데이터는 실제 사용자 기록이 아닌 합성 fixture입니다. PDF 재생성은 `build_sa_pdf.py`/`verify_sa_pdf.py`를 사용하며 Reportlab·fontTools와 Noto CJK 폰트·Poppler가 추가로 필요합니다. PDF는 이미 만들어져 있으므로 웹 배포 시 다시 만들 필요는 없습니다.

GitHub Pages는 **main 브랜치 / 루트**를 사용합니다. `.nojekyll`로 정적 파일을 그대로 게시합니다. 소스를 수정했다면 실행 HTML도 다시 빌드하여 함께 커밋해야 합니다.
